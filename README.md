# GF Server Manager — Releases

Официальный публичный канал обновлений **GF Server Manager**.

Этот репозиторий хранит только manifests и готовые Release-пакеты. Исходный код приложения здесь не публикуется.

- `manifest-stable.json` — стабильный канал.
- `manifest-experimental.json` — экспериментальный канал.
- Бинарные ZIP-пакеты публикуются через GitHub Releases.

Клиент GF Server Manager проверяет SHA-256 пакета перед запуском отдельного `GFServerManager.Updater.exe`.
